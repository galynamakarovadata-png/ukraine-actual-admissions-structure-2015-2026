# Перелік джерел фінансування у сфері освіти України

Добірка актуальних державних програм, міжнародних фондів, грантодавців та агрегаторів можливостей для розвитку освітніх проєктів в Україні.

| Назва фонду / Програми | Тип джерела | На що надається фінансування | Посилання |
| :--- | :--- | :--- | :--- |
| **Державні гранти на навчання (МОН України)** | Державне фінансування | Часткове або повне покриття вартості контрактного навчання у закладах вищої та фахової передвищої освіти для вступників. | [mon.gov.ua](https://mon.gov.ua) |
| **Erasmus+ (Програма ЄС)** | Міжнародна грантова програма | Розвиток потенціалу вищої та професійної освіти, академічна мобільність, цифровізація та міжнародні партнерства для закладів освіти і ГО. | [erasmusplus.org.ua](https://erasmusplus.org.ua) |
| **Міжнародний фонд «Відродження» (Освітня програма)** | Благодійний фонд / Донор | Гранти для громадських організацій та ініціатив на освітні реформи, доступність навчання, дослідження та аналітику в освіті. | [irf.ua](https://irf.ua) |
| **KSE Foundation (Програма Talents for Ukraine)** | Благодійний фонд | Грантова підтримка (по $5 000) для талановитих українців, освітян, науковців та авторів освітніх проєктів. | [foundation.kse.ua](https://kse.ua) |
| **UNICEF Україна (Освітні програми)** | Міжнародна організація | Відновлення доступу до освіти, облаштування укриттів у школах, цифрові освітні центри та підтримка вчителів. | [unicef.org/ukraine](https://unicef.org) |
| **IREX в Україні** | Міжнародна організація | Грантові програми для закладів освіти, підвищення кваліфікації викладачів, медіаграмотність та розвиток молоді. | [irex.org](https://irex.org) |
| **House of Europe (Дім Європи)** | Програма ЄС | Інфраструктурні гранти, програми обміну, стипендії та фінансування проєктів у сфері освіти, науки й роботи з молоддю. | [houseofeurope.org.ua](https://houseofeurope.org.ua) |
| **GetGrant (Розділ «Освіта»)** | Каталог / Агрегатор грантів | Актуальна база відкритих грантових конкурсів для шкіл, університетів, освітніх ГО та вчителів в Україні. | [getgrant.ua](https://getgrant.ua) |
| **Центр розвитку «ЧАС ЗМІН»** | Каталог / Агрегатор грантів | Регулярні добірки українських та міжнародних грантів і стипендій у сфері освіти, науки та досліджень. | [chaszmin.com.ua](https://chaszmin.com.ua) |
